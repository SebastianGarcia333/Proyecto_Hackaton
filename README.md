# Kase · Comidas rápidas

Kase es una tienda online de comidas rápidas: hamburguesas, perros calientes, acompañantes y bebidas. El usuario explora el menú, filtra por categoría y arma su **ticket** (carrito), que se guarda en `localStorage` y sigue ahí aunque se cierre o recargue la página.

## Páginas
| Página | Archivos |
|---|---|
| Inicio (portada, menú, nosotros, contacto) | `index.html` · `css/inicio.css` · `js/inicio.js` |
| Ticket (revisar, ajustar y confirmar) | `ticket.html` · `css/ticket.css` · `js/ticket.js` |
| Compartidos | `css/base.css` · `js/almacenamiento.js` |

## Tecnologías
HTML5 semántico, CSS3 (variables, grid/flex, animaciones), Bootstrap 5 (rejilla y panel lateral) y JavaScript puro.

## Cómo usarlo
Abre `index.html` en el navegador. No requiere instalación.
